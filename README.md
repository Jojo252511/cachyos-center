# cachyos-center

Deutschsprachige Desktop-App für CachyOS mit Hyprland: Systemübersicht, sichere Paketverwaltung,
Updatekontrolle und ein lokaler, rein lesender MCP-Server für KI-Assistenten.

> Unabhängiges Community-Projekt, kein offizielles CachyOS-Produkt.

Der Aufbau befindet sich in Entwicklung. Architektur, Sicherheitsmodell und Bedienung werden unter
[`docs/`](docs/) beschrieben.
