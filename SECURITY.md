# Sicherheitsrichtlinie

cachyos-center enthält einen privilegierten Helper, der Paketoperationen mit Root-Rechten
ausführt. Sicherheitsprobleme bitte **nicht** öffentlich als Issue melden, sondern über die
private Meldefunktion von GitHub („Report a vulnerability“ im Reiter *Security* des Repositorys).

Bitte angeben: betroffene Version, Beschreibung, Schritte zur Reproduktion und mögliche
Auswirkungen. Das Sicherheitsmodell ist in [docs/sicherheitsmodell.md](docs/sicherheitsmodell.md)
beschrieben.
